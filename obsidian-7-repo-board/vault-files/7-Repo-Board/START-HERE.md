# 7-Repo Board — 已装进你的 vault

## 立刻打开

1. 打开文件：`7-Repo-Board/7-Repo-Board.canvas`
2. 设置 → 外观 → CSS 代码片段 → 确认 **7-repo-board** 已勾选

## 更接近原图（可选，2 分钟）

1. 安装主题 **Minimal**（社区主题 / [kepano/obsidian-minimal](https://github.com/kepano/obsidian-minimal)）
2. 安装 **Minimal Theme Settings** 插件，配色选 **Flexoki**（或手动用 [kepano/flexoki](https://github.com/kepano/flexoki)）
3. 外观选深色模式

## 安全说明

安装脚本只会写入：

- `7-Repo-Board/`（本目录）
- `.obsidian/snippets/7-repo-board.css`
- 在 `appearance.json` 里把 `7-repo-board` 加入 `enabledCssSnippets`

不会改你的主题、插件列表或其他笔记。
