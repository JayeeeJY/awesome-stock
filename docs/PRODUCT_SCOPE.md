# 首发候选范围

目标为 GitHub 上可自行部署的个人投资工作台，六区为 Cockpit、Portfolio、Research、Plan、Evolve、Academy，另设 Settings。完整已实现功能见 README。

本候选提供真实持久化、账号、核账、版本依据、业务闭环、可选用户自备连接；不是临时数据演示。默认不需要 AI。没有实时行情时诚实显示缺失，AI 不代替人工判断。

当前边界：单所有者、本机、账户级FIFO或加权平均成本、多头成交、账户币种分别核算。支持按用户记录的有效汇率折算USD汇总，缺汇率时不合计。没有券商下单/同步、空头/期权账本、公网多用户、旧私有库迁移、自动执行规则或后台模型任务。

视觉以自用版的侧栏、顶栏、蓝色页面头部和紧凑组件为基准，保留独立 Owner 实现及真实功能。本地审阅候选已包含自用版视觉与Logo，来源权利状态仍待确认；不能据此视为获得公开分发授权。

源码分发为当前候选边界；用户从官方固定摘要拉取基础镜像并本机构建。不发布预构建镜像、模型权重、数据样本中的私人记录或旧 Git 历史。项目自有代码许可已确定为AGPL-3.0-only，署名Evan；本次只启用开源许可。2026-10-06本人已通过全功能验收，并明确本次正式首发采用「本人全功能验收＋最终工程验证」，替代旧长期/多人试用前置要求；不改成alpha。最终版本号、第三方来源、具体安全风险/平台边界及公开发行批准仍待收口。

2026-10-06 / P227：用户选择A方案，本次首发只支持macOS Apple Silicon（arm64）原生源码安装；Docker入口和部署文件从源码包及GitHub审阅树排除，不分发预构建镜像。Windows/Linux/Intel Mac不列入首发正式支持。功能/视觉与已签收P223保持一致。
