# 可选模型与行情

模型和自有 API 连接默认关闭，账号与费用由各使用者承担。默认行情候选为无需 Key 的 Yahoo 公共日线，仅在主动点击查询后联网；无启动抓取、自动换源或实时行情承诺。该来源公开接入使用条件仍待发行审阅，并非官方授权证明。Community 没有统一开发者 Key、不代付；不使用外部查询时账本和手工业务仍可使用。

| 服务 | 设置内容 | 当前用途 |
| --- | --- | --- |
| Yahoo 公共日线 | 无需 Key；选择市场和标的 | 默认候选；主动查询美股/沪深 A 股/港股已完成日线，先核对后保存；来源使用审阅待完成 |
| OpenAI | 自己有权限的模型名称、自己的 API Key | 手动预览并确认后发送研究上下文；固定 Responses API，store=false |
| DeepSeek | 自己有权限的模型 ID、自己的 API Key | 预览确认后发送；固定 Chat Completions API，只接受完整文本结果 |
| Ollama | 已在本机安装的模型名称，Key 留空 | 同样的主动 AI 流程；模型和运行资源由使用者自行准备 |
| Alpha Vantage | 自己的 API Key、美国或沪深 A 股代码 | 主动查询 USD/CNY 日级价格及历史；美国市场另支持公司概览和新闻来源 |
| EODHD | 自己的 API Token、香港股票代码 | 独立港股连接；核对标的/交易所/HKD 后读取日级价格与历史 |

进入“设置 → 数据与 AI 连接”。模型名称不是登录邮箱或网站账号。点击「保存模型连接」后显示持久反馈，Key 输入框清空但凭据留在当前进程；保存不是调用验证。在同一模型卡片点击「测试连接」，确认固定测试文字后才发送一次请求；成功或具体错误分别显示。DeepSeek 预填 deepseek-flash，亦可改为自己有权限的模型 ID。不要把 Key 发到 Issue 或对话里。

源码运行的 Ollama 固定地址为 `127.0.0.1:11434`；容器使用 `host.docker.internal:11434`。使用者需确认自己的模型服务允许对应连接，同时避免公开暴露端口。应用不接收任意服务 URL，不会从本地失败自动切换到云端。

Key 只在服务内存中。退出、改密、服务重启会清除；不写数据库，不进入备份/JSON 导出。调用有超时和响应体上限；失败不会自动重试或更换供应商。关闭连接后不能继续发起该服务请求。

AI 发送前显示将提交的上下文，必须主动确认。输出仅供人工阅读，不自动写交易、启用规则或执行代码。服务商可能独立保留请求；应用的内存 Key 策略不等于服务商零留存保证。

当前未实现通用 OpenAI-compatible URL、券商连接、统一付费账户或模型权重下载。协议测试使用离线合成传输；真实账号权限、额度与用户本机 Ollama 可达性须实际验收。

DeepSeek 协议依据：[官方 Chat Completions 文档](https://api-docs.deepseek.com/api/create-chat-completion/)，核对日期 2026-10-06。适配固定 `api.deepseek.com/chat/completions`，限制输出预算，不请求工具；截断、过滤或工具调用结束不当作完整草稿。模型 ID 由用户按当前权限填写，不保证所有模型模式均通过真实验收。

## 行情查询与保存

选择市场后再输入代码：沪深A股使用六位产品代码，供应商请求映射为.SHH/.SHZ；香港数字代码规范为五位，如00700，供应商使用0700.HK。拒绝不支持的代码/币种，失败不自动改用另一服务。港股凭据与Alpha Vantage分别启用或关闭。

日级价格不是实时成交价；同源上一条日线可作为昨收，缺失保持未知。历史可主动选择最近100根或260根，实际返回不足时不补造数据。查询后需明确确认才保存，保存的来源版本与研究报告可追溯。EODHD 香港每次查询先读取标的资料，再读取日线，合计两次供应商请求，可能消耗两次额度。Yahoo 公共源一次请求，核对响应标的/币种/证券类型，不使用任何已配置的 Key。

自有 Alpha Vantage/EODHD 价格使用原始未复权OHLC；Yahoo 公共源使用供应商 OHLCV、不读取 adjclose，不将其标记为已核验的未复权/全复权价格。公共源最多一年日线，排除未完成交易日；固定地址、禁止重定向、30秒超时/256KiB响应上限，使用系统网络代理配置而不转发模型/行情 Key。EODHD成交量按供应商拆股调整，界面单独标明，不将adjusted_close混作原始价格。上海/香港日期用于对应市场的时效判断，美股仍按UTC保守校验，未承诺完整交易所收盘及节假日日历。

A股和港股的公司概览/新闻连接尚未覆盖。启用、离线测试通过与真实账号权限通过分别记录；发行前仍需用户自己的服务环境验收。
