# 模型与行情配置指南

适用：Community v1.0.0。入口：「系统设置 → 数据与 AI 连接」，本机默认地址 [连接设置](http://127.0.0.1:4322/settings/connections)。如果启动时改了端口，请使用自己的端口。

**不配置也能使用账本、手工研究和计划。模型与行情独立，均使用各用户自己的账号/额度；项目没有统一 Key，也不代付。** 首发暂缓 Yahoo 免 Key 行情。可在「持仓 → 管理持仓 → 记录价格快照」手工保存带来源的价格；CSV 仅导入成交记录，不导入行情/日线，见 [第一次使用](QUICKSTART.md)。

## 一、云端模型：准备 → 保存 → 测试 → 对话

### 准备自己的模型凭据

| 选择 | 去哪里准备 | 在本应用填写什么 |
| --- | --- | --- |
| DeepSeek 云端 | [官方 API Key 控制台](https://platform.deepseek.com/api_keys)，参照 [官方接入说明](https://api-docs.deepseek.com/quick_start) | 自己的 Key；实际模型 ID，例如 `deepseek-flash` 或自己有权限的 `deepseek-v4-pro` |
| OpenAI 云端 | [官方 API Key 页面](https://platform.openai.com/api-keys)，参照 [Responses API](https://platform.openai.com/docs/api-reference/responses) | 自己的 Key；自己账号有权限、支持 Responses API 的模型 ID |

模型 ID 不是邮箱、用户名或“DeepSeek”服务名称；ChatGPT 订阅也不是 API Key。按服务商控制台确认 API 权限、额度及计费；网站能聊天不保证 API 可用。以上官方入口于2026-10-07核对，模型与权限可能调整，以你的控制台和官方文档为准。

### 保存和测试

1. 在「模型服务」选择供应商，填写模型 ID，将自己的 Key 粘贴到密码输入框。无需填写服务器地址。
2. 点击「保存模型连接」。看到配置保存反馈后，Key 输入框会清空，凭据仍在当前服务内存中；这一步没有发送模型请求。
3. 在同一卡片的「测试连接」点击测试按钮，核对固定测试文字并确认发送。只发送这一句测试，不读取你的持仓或研究材料；可能消耗自己的 API 额度。
4. 看到绿色「连接测试成功」和模型回复才表示一次真实调用成功。「尚未验证真实调用」只表示已配置。测试成功不保证所有问题都能在输出预算内得到完整答案。

修改供应商或模型后需重新保存并测试；刷新状态只读取当前连接状态，不发送模型请求。

### 使用 Ask Awesome 自由提问

1. 点击页面顶部 Awesome 图标打开「Ask Awesome」，在自由输入框写问题，例如“用三个要点解释市盈率的局限”。可以直接问，不必先填写研究任务表单。
2. 如果需要基于账本或研究作答，主动载入当前页面材料；展开并核对附加内容，不要发送不需要的私人信息。打开面板不会自动读材料或发请求。
3. 点击预览，核对本次问题、附加材料及将发送的对话历史，再确认发送。完整模型回复显示后可以继续追问；每次发送都使用自己的额度。
4. 回复是待核验草稿，不自动保存为事实、不下单、不启用规则、不执行代码。研究页的「研究助手」仍可用于结构化材料任务，它与自由对话共用你配置的模型服务。

当前对话只在页面内存中，刷新清除；切换页面保留当前草稿和已载入原上下文，不自动换成新页面数据。需要保存研究草稿时使用对应研究流程。

## 二、Ollama 本地模型：由你自行安装

1. 按 [Ollama 官方快速开始](https://docs.ollama.com/quickstart) 安装并打开 Ollama，选择适合自己 Mac 内存的**本地模型**并下载。模型权重不随本应用提供；首次下载需要网络、存储和设备资源。
2. 用 `ollama ls` 查看已安装模型，必要时按 [官方 CLI 文档](https://docs.ollama.com/cli) 使用 `ollama pull 模型名` 下载。复制列表里完整的名称（包括标签）。保持 Ollama 服务运行；服务未运行时可使用 `ollama serve`。
3. 在本应用选择「本机 Ollama」，填写已安装的模型名，API Key 留空，保存并按上一节测试。固定连接 `127.0.0.1:11434`；本应用不接收自定义服务器 URL，也不会自动改用云端。

这里只接入本机模型，不提供 Ollama 云端计费账号或下载器。运行本地模型消耗自己的设备资源，不通过项目共享云端额度。不要公开暴露本地服务端口。

## 三、行情：配置自己的 API → 查询预览 → 确认保存

### 准备行情账号

| 市场 | 自有服务 | 官方获取入口 | 应用代码示例 |
| --- | --- | --- | --- |
| 美国 · USD | Alpha Vantage | [申请 API Key](https://www.alphavantage.co/support/#api-key)、[API 文档](https://www.alphavantage.co/documentation/) | `AAPL` |
| 沪深 A 股 · CNY | Alpha Vantage | 同上；核对你的账号是否覆盖所需数据 | `600104`、`000002` |
| 香港 · HKD | EODHD | [注册账号](https://eodhd.com/register)、[官方文档](https://eodhd.com/financial-apis/)；在自己的账号获取 API Token 并确认港股权限 | `00700`（也接受 `0700`） |

代码仅用于说明输入格式，不是投资建议，也不承诺服务商免费账户覆盖全部市场/历史。服务套餐、权限和额度以供应商为准；**开源许可不包含行情账号或数据使用权**。无需填入开发者共享 Key。

### 查询和保存

1. 美股/A股：填写自己的 Alpha Vantage Key，点击「启用行情连接」。港股：在「港股日线连接」填写自己的 EODHD Token，点击「启用港股连接」。两套凭据独立；启用只保存配置，不抓取数据。
2. 在「行情市场」选择对应市场，再填代码；不要将登录账号或公司中文名当作标的代码。美国使用供应商支持的代码，A股使用六位代码，港股保存为五位代码。
3. 点击「主动查询日级价格」。看到价格、币种、日期与来源预览，表示该查询返回了可用数据；**此时尚未保存**。核对无误后点击「确认保存价格快照」，再到持仓/研究读取保存记录。
4. 需要日线历史时选择最近100根或保留最近260根，点击「主动查询最近日线」，展开核对内容后点击「确认保存日线快照」。价格与历史是两类独立快照，不会互相替代。
5. 公司资料与相关新闻按钮当前仅支持美国市场，均需主动查询、核对、确认保存；新闻只保存来源索引，不自动读取全文或图片。

日级价格**不是实时成交价**。历史是未复权OHLC，拆股/分红可能造成跳变；不足周期保持待补，不补造交易日。港股成交量按供应商拆股调整，单独标明。EODHD每次主动查询包含标的核对与日线两次请求，可能消耗两次额度；关闭港股连接不会关闭Alpha Vantage。

查询失败不会自动重试、换源或改用手工价格；再次点击会发起新的请求。长历史权限不足会报错，不会悄悄降为短历史。美股日期按UTC保守校验，A股/港股按对应市场日期判断，未承诺完整交易所节假日日历。

## 四、看到错误怎么办

| 现象 | 操作 |
| --- | --- |
| 配置保存了，但没有模型回复 | 保存不发请求；点击同一卡片「测试连接」，核对后确认发送 |
| Key 输入框保存后变空 | 正常。看保存反馈与状态；凭据仍在本次进程。更换配置需重新填Key |
| 无效Key、权限或额度错误 | 去自己的服务商控制台核对Key、模型/市场权限和余额，再重新配置；不要反复点击消耗额度 |
| 模型不存在或返回不完整/无可用文本 | 核对实际模型ID与协议兼容；缩短问题/材料后重新预览。之前测试成功不等于这次回复成功 |
| Ollama不可达/模型缺失 | 确认本机服务运行在11434，模型名与 `ollama ls` 一致；不会自动切云端 |
| 重启或退出后连接关闭 | 内存Key已清除，重新填写、保存、测试；业务数据和已保存来源仍保留 |
| 价格预览消失/过期或币种不符 | 重新查询并核对；没有确认保存不会写进业务账本 |
| 连接状态读取失败 | 点击「刷新状态」核对，不把旧状态当成功；无需清空账本 |

Key不写入数据库、备份或JSON导出；关闭对应连接、退出登录、改密或服务重启会清除。应用的内存策略不代表服务商不保留请求。不要发送Key或备份给项目维护者。当前未提供自定义OpenAI-compatible地址、券商连接、自动下单或模型下载功能。

更多故障处理见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)；安装与完整备份见 [OWNER_INSTALL.md](../OWNER_INSTALL.md)。Yahoo暂缓不会删除已有来源、价格或固定报告；历史记录不代表现在仍可查询该接口。
