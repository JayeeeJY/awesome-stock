# 数据与隐私

Owner 是一台设备上的单所有者账本。业务保存在 SQLite；默认目录 `.owner-state`，也可指定 `--data-dir`。浏览器不是数据库，更换浏览器不会迁移数据。运行账号对自己的数据有读取权限，登录口令不是磁盘加密。

口令保存为独立随机盐的 PBKDF2 摘要，不存明文。会话和服务 Key 只在内存中，重启需重新登录/配置。无默认账号、第二人注册、忘记口令找回或公网多用户部署。

备份包括账号口令摘要、账户、成交、现金流、研究、计划、复盘、Ask 问答和历史；未加密。备份恢复需使用备份时的口令。JSON 导出只含业务资料，不含账号凭据、会话、Ask 对话或内部审计；自由文本仍可能含个人信息。JSON 不是账号恢复包。

归档保留历史。设置里的“预览清空范围”只读；清空需当前口令、准确确认文字及最新预览令牌，保留账号但清除当前业务和审计。既有备份、下载文件和操作系统快照不会同时消失。可另行删除指定应用备份；不承诺磁盘物理安全擦除。

手工业务无需外部服务。首发暂缓 Yahoo 公共行情接口，不向该服务发起查询；旧查询入口拒绝而不联网或写入。已保存的来源记录与固定历史保持原样。没有启动抓取或失败后自动换源。主动使用模型/行情时按设置说明发送必要内容。项目不自动上传账本、安装遥测或同步云盘。不得把真实账本、备份、API Key 或券商导出放进公开 Issue。


Ask Awesome对话：已完成的问答写入 `--data-dir` 里的账本库，关闭页面或重启后可按对话恢复。升级只增加对话表，不删除已保存的问答。保存的是问题、回答、失败说明、服务商和模型名。不写入 API Key。模型、Alpha Vantage 和 EODHD 的密钥只在内存里。成功启用且不少于 12 个字符的密钥，会在账本库记下 HMAC-SHA256（每套数据目录一把随机密钥，不保存可还原的原文，摘要表有上限）。写入时只按词边界去掉对得上的整段密钥，以及带左边界的 sk-/rk-/pk- 和含数字的长 bearer 样式；普通词语不会被改写。短于 12 个字符的密钥只在本进程里精确匹配。也不把账本持仓或页面材料自动抄进对话。继续追问只把已成功的问答与你当次选定的材料列入发送预览，确认后才发到你配置的模型；失败回答会留下但不当作后续依据，超限不自动截断。不会自动写成研究笔记。整库备份包含这些问答；JSON 导出不含。设置里的清空会删除当前库中的对话、密钥摘要和那把随机 HMAC 密钥，已有备份需要另行删除。
