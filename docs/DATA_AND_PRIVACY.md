# 数据与隐私

Owner 是一台设备上的单所有者账本。业务保存在 SQLite；默认目录 `.owner-state`，也可指定 `--data-dir`。浏览器不是数据库，更换浏览器不会迁移数据。运行账号对自己的数据有读取权限，登录口令不是磁盘加密。

口令保存为独立随机盐的 PBKDF2 摘要，不存明文。会话和服务 Key 只在内存中，重启需重新登录/配置。无默认账号、第二人注册、忘记口令找回或公网多用户部署。

备份包括账号口令摘要、账户、成交、现金流、研究、计划、复盘和历史；未加密。备份恢复需使用备份时的口令。JSON 导出只含业务资料，不含账号凭据、会话或内部审计；自由文本仍可能含个人信息。JSON 不是账号恢复包。

归档保留历史。设置里的“预览清空范围”只读；清空需当前口令、准确确认文字及最新预览令牌，保留账号但清除当前业务和审计。既有备份、下载文件和操作系统快照不会同时消失。可另行删除指定应用备份；不承诺磁盘物理安全擦除。

手工业务无需外部服务。默认公共日线候选不需要 Key，仅在点击查询时向 query1.finance.yahoo.com 发送所选标的和日线范围，不读取账本或其他服务凭据；标准系统网络代理可参与此公开查询。没有启动抓取或失败后自动换源。其公开接入使用条件仍待发行审阅。主动使用模型/行情时按设置说明发送必要内容。项目不自动上传账本、安装遥测或同步云盘。不得把真实账本、备份、API Key 或券商导出放进公开 Issue。


Ask Awesome对话：问答仅保留在当前页面内存，关闭面板/切换页面可继续，刷新或退出清除。继续追问会把本次已成功问答与选定材料列入发送预览，确认后才发到用户配置的模型；失败回答不作为后续依据，超限不自动截断。不会自动写成研究笔记，不进入备份或导出。
