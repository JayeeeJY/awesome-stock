# 第一次使用 Awesome Stock Community

适用：v1.0.0，macOS Apple Silicon（arm64），Python 3.10+。本程序在你自己的电脑运行，每个数据目录管理一个本地账号。没有默认账号密码，也没有统一模型或行情 Key。

## 1. 安装、创建本地账号

下载源码包、解压并进入 `awesome-stock-owner` 目录；如通过 GitHub 下载仓库源码，则进入解压后的仓库目录。打开终端，在该目录运行：

```sh
python3 --version
python3 start_owner.py --data-dir "$HOME/Awesome-Stock-Data" --open-browser
```

Python 版本须为 3.10 或以上。浏览器打开 [本地入口](http://127.0.0.1:4322/ledger)，按页面创建用户名与口令。**用户名/口令只用于登录这个本地账本，与模型服务账号无关。** 保留终端运行；关闭终端或按 Ctrl+C 会停止服务。再次使用时运行同一条启动命令，继续使用同一个数据目录。

端口占用可添加 `--port 4324`，并访问对应端口。具体安装、升级和恢复见 [安装说明](../OWNER_INSTALL.md)。首发不包含 Docker；Windows、Linux 和 Intel Mac 暂不在正式支持范围。

## 2. 先建立账本，不必配置 API

1. 进入「投资组合 → 资金账户」，建立自己的资金账户，选择币种和成本方式。**期初现金填写准备录入的第一笔成交之前的余额**，避免再录入历史买卖后重复扣款。成本方式保存后不可直接切换。
2. 进入「投资组合 → 资金流水」，记录后续出入金；资金更正保留历史。
3. 进入「投资组合 → 交易流水」，录入买入、卖出、数量、价格、费用与带时区的成交时间；卖出不能超过持仓。先核对少量记录再批量导入。
4. 如已有成交表，进入「系统设置 → 导入与导出」，下载 CSV 模板、选择导入账户、填好模板并上传，点击「预览导入」。核对现金、持仓影响和错误，再确认导入。**CSV 导入的是成交记录，不是价格、日线或任意券商表格。** 当前限制为 UTF-8、32 KiB、200 条；金额用普通小数，保留稳定的成交编号以跳过重复项。
5. 进入「投资组合 → 持仓」核对现金、数量、成本与币种。打开「管理持仓 → 记录价格快照」，填写自己核对的标的、币种、价格、时间和来源，再保存。**缺少价格或汇率会显示待补，不等于资产为零。** 跨币种汇总使用已保存的有效汇率；缺失部分不合计。

无需配置 AI 或行情服务即可使用账本、手工价格、CSV 成交导入、笔记、判断、计划与复盘。首发暂不提供 Yahoo 免 Key 行情，应用不会偷偷请求其他数据源。

## 3. 从研究走到计划和复盘

进入「研究 → 个股研究」，输入标的并点击「载入本地研究材料」。这一步读取已保存的本地材料，不会搜索互联网、自动生成报告或调用模型；没有材料会显示缺口。

在「研究笔记」保存论点与证据，在「投资判断」记录支持理由、反方证据和失效条件。再到「计划」创建方案或做配置/预算/交易前试算。保存版本固定当时依据；后续修改产生新版本，不改写旧引用。录入实际成交时可关联判断和执行计划。计划状态、试算和规则都不代表真实下单。

在「进化」记录投资日记和决策复盘，分别评价过程与结果，再按自己的判断调整规则。AI 是可选助手；开启规则和执行动作由你决定。

## 4. 想用 AI 或自动行情时，再配置

| 你想做什么 | 下一步 |
| --- | --- |
| 云端 AI 对话/整理材料 | 「系统设置 → 数据与 AI 连接」选择 DeepSeek 或 OpenAI，填写自己的 API Key 和模型 ID，保存后点击「测试连接」 |
| 本机运行模型 | 自己安装并启动 Ollama、下载适合设备的本地模型；选择 Ollama，填写已安装的模型名，Key 留空 |
| 美股或沪深 A 股日级行情 | 配置自己的 Alpha Vantage Key，选择市场与代码，主动查询后核对并确认保存 |
| 港股日级行情 | 单独配置自己的 EODHD Token，选择港股市场与代码，主动查询后核对并确认保存 |

完整步骤、官方 Key 入口、成功反馈与错误处理见 **[模型与行情配置指南](OPTIONAL_PROVIDERS.md)**；页面也提供「模型配置与使用步骤」「行情配置与保存步骤」可展开指引。

**费用由各使用者自己的服务商账号承担**，项目不代付、不提供共享 Key。模型与行情是两套独立连接，配置其中一项不会启用另一项。保存配置不等于测试成功；API 调用可能收费，发送前按页面核对并确认。Key 输入框在保存后清空，但凭据仅留在本次服务内存；退出登录、改密、关闭连接或重启后需重新配置。不要将 Key 贴到 Issue、截图或对话里。

## 5. 保留备份

进入「系统设置 → 账户与数据」（连接页侧栏标为「账户与备份管理」），创建完整备份，将页面显示的 `backups/备份名称` 整个目录复制到独立位置。备份包含口令摘要与业务历史，**未加密**；不要只复制正在运行的 SQLite 文件。

恢复时按 [安装说明](../OWNER_INSTALL.md#备份与恢复) 使用不存在的新目录，检查后再切换。升级前先备份、保留旧源码，继续使用原数据目录。JSON 导出适合查看和转移副本，不替代完整备份恢复。

遇到问题见 [故障处理](TROUBLESHOOTING.md)。不要删除数据目录、清空业务或重建账号来解决登录问题。
