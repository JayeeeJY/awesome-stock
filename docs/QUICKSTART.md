# 第一次使用

本次首发支持macOS Apple Silicon（arm64）原生源码安装；Docker及其他桌面平台暂缓。

1. 按 [安装说明](../OWNER_INSTALL.md) 启动，在页面创建自己的账号。
2. 在“资产 → 账户与交易”建立资金账户。期初现金填第一笔成交之前的余额；后续资金变化记入“入金与出金”。
3. 手工录入买卖，或下载 CSV 模板、选择目标账户、上传并预览。核对后才确认导入；保留稳定的成交编号以防重复。
4. 在“我的持仓”核对数量、成本、现金和币种。价格缺失不等于资产为零。
5. 整理候选和证据，保存研究笔记，再创建投资判断。计划引用确定的判断版本；记录成交时可选择关联判断。
6. 复盘时核对历史依据，分别记录过程、结果与改进。计划状态和规则由人工管理，不代表真实成交或自动下单。
7. 在“设置 → 数据与备份”创建备份，并妥善保管独立副本；需要时恢复到新目录验证。

首发暂缓 Yahoo 免 Key 接口。可在持仓页「管理持仓 → 记录价格快照」手工录入价格和来源，或在「设置 → 导入与导出」预览导入 CSV。主动查询行情需在「设置 → 数据与 AI 连接」配置自己的 API。模型需用户自配 Key 或 Ollama，保存后在同一卡片测试。模型与自有行情均可稍后配置，见 [可选服务](OPTIONAL_PROVIDERS.md)。当前发布前验证请用合成数据。不要通过删除数据目录、重置业务来解决登录问题。
