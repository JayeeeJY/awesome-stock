# 常见问题

- **打不开页面**：确认服务终端仍运行；本次首发为原生源码安装，默认端口 4322。不要直接双击 HTML。端口占用时按安装文档更换端口。
- **重启后要求登录/重新填 Key**：正常；会话和 Key 在内存中，业务记录在磁盘。若出现创建账号页，先确认启动时的--data-dir 数据目录是否与之前一致，不要重复初始化。
- **输入无效**：账号使用页面允许的字符。金额/数量用普通十进制，最多 12 位整数和 8 位小数，不使用科学计数法；检查成交时间。模型名称不能填登录邮箱。
- **更正被拒绝**：修改会核验后续交易，不能造成历史现金透支或超卖；先核对成交时间和资金流水。冲突时重新读取最新版本再更正，不盲目重复保存。
- **没有市值**：缺少有效价格或价格过期会显示缺失。主动补充价格快照；不同币种仍不自动合并。
- **AI 未连接**：先在设置启用自己的服务，再执行主动调用。检查模型权限、额度、网络或本机 Ollama；配置成功不是实际调用成功。应用不会改用开发者 Key。
- **忘记口令**：没有找回入口。保留数据库和备份，不重置数据；恢复旧备份需备份当时口令。
- **准备升级**：先备份并复制到独立位置，保留旧源码，再替换程序，继续使用原数据目录。见 [恢复步骤](../OWNER_INSTALL.md)。

反馈请写清版本候选、操作步骤、预期与实际结果，使用合成样例并移除秘密和个人数据。安全问题不要放公开 Issue，见 SECURITY.md。

模型配置、Key清空、测试与查询失败的分步处理见[配置指南](OPTIONAL_PROVIDERS.md#四看到错误怎么办)。
