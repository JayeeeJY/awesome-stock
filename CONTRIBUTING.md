# Feedback and contributions

The first public release is intended to accept product feedback and issues only. External code contributions are not being accepted. A future change to that policy requires a published contribution process and rights review; no CLA, DCO or copyright assignment is silently imposed.

For a useful issue, include the candidate/release identifier, operating system, source or container installation, exact steps, expected behavior and actual behavior. Reproduce with synthetic data where possible. Do not attach credentials, brokerage exports, private research, database files or backups.

Security reports follow SECURITY.md; do not publish exploit details in a public issue. No response-time or support commitment is currently offered. The repository and its private reporting channel are not yet publicly enabled.

Local maintainers can follow docs/DEVELOPMENT.md for checks. Passing tests does not approve a contribution, license, release or publication.
